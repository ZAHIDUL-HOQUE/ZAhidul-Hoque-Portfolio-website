Vehicle Exterior Damage Detection System

An end-to-end computer vision and inspection grading application powered by Prototypical Mask R-CNN (ResNet-50-FPN) trained on the CarDD dataset.

Public Repository Python Apache 2.0 MSc Thesis (ID: 23097240)

Masters-thesis-project-of-Zahidul-Hoque-University-of-Hertfordshire

Automated detection, pixel-level instance segmentation, and inspection grading for six critical exterior vehicle damages. Equipped with interactive Streamlit web dashboard, confidence filtering, and non-maximum suppression (NMS) overlap tuning.
